# Memory Blink mainboard
This contains the KiCad project for the PCB of MemoryBlink.

I plan on including the following:
- headers for the ESP32
- headers for 16x02 LCD module
- PCF8574 8-bit expander chip on the board {components}
- 4 colored LEDs (red, green, blue, yellow) and 4 white LEDs {components}
- 4 buttons for inputs (tht holes)
- 1 buzzer (tht holes)
